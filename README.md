🛠️ Deployment on GitHub Pages
Follow these steps to deploy this website:
Create a Repository: Go to GitHub and create a new repository (e.g., mindoze-therapy).
Upload Files: Push your index.html, styles.css, and script.js to the main branch.

Enable Pages:
Go to Settings > Pages.
Under Build and deployment, set the source to Deploy from a branch.
Select the main branch and the / (root) folder.

Click Save.
View Site: Your site will be live at https://santosh46j.github.io/mindoze-therapy/#contact within a few minutes.
